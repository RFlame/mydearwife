## 功能映射

- 保留 20 关、40 款原创零食、12 位原创顾客、难度预设、星级、金币、解锁、设备升级和两类图鉴。
- 保留左侧屏幕外篮口撒落，全部落地前锁定交互；撒落入场和单件抛落使用核心与渲染共享的短时长参数。
- 保留真实旋转包装遮挡、露出比例门槛、辅助触摸热区、整桌拖动、秤区与收银员过道禁放。
- 移除四个固定集货区、区域退货、POS 自动/手动开关和任意位置双击结算。零食直接在桌面自由整理。
- 同款包装表面间距不超过 18 个桌面逻辑像素时连通；该同款的全部未结算物品必须位于同一个连通分量。堆内任一成员周边 28 像素内出现异款时暂不结算，移开异款后立即重新检测。
- 聚堆检测只发生在撒落完成、拖动松手/取消和吸附整理后；拖动途中不会让物品脱手。多个合格堆按首件 `uid` 确定 FIFO 顺序，已入队物品不再参与桌面检测。
- 批次飞行约 0.18 秒，组内仅有极短错峰。当前批结束在同一逻辑更新内结算并启动下一批，没有冷却等待；较大帧 delta 也能连续跨批推进。
- 上一批秤上短驻留、LED 数字滚动、价签和装袋反馈与下一批飞行并行。LED 从当前值插值，不归零跳变；多个短时价签可并存，换客不会清除上一位顾客最后一批价签。
- 保留连击、耐心、礼盒、盲袋、装袋、收银员反馈、暂停、失败与完成结算。盲袋首次拿起时揭示，自动入秤前也会强制揭示。
- 吸附把当前可拿取的同款在原位置附近聚拢，再统一检测，次数仍受升级影响；不再送往固定区域。
- 升级页保留电子秤 LED 速度和吸附次数。旧称重台等级仍兼容存档，但自由聚堆没有台位格数容量，不再出售该无实际作用的升级。
- 旧额外台位、冻结道具入口没有重新加入；轻松预设提供自动提示。最上层物品始终可拿取，不依赖旧防死锁道具。
- 使用本地 Web Audio 合成音效，不包含 WAV；不支持时无声降级。没有连续背景音乐。
- 存档严格使用 `window.xhs.miniTool` Storage，数据为 JSON 字符串；版本或方法不满足时明确提示仅保留到关闭前，不使用浏览器存储替代。
- 振动与窗口信息按在线文档做客户端版本和方法检测。未接入无关 AI、定位、陀螺仪、关注、赞赏或云能力。

## 已明确的适配差异

- 这是独立 ES2017 + Canvas 2D 实现。JS 种子可复现自身布局，但不承诺逐坐标复现 Godot RNG。
- 零食与人物沿用原创 SVG；音效改为实时合成；字体使用系统字体栈。
- 自由聚堆与顾客切换由同一核心状态机驱动，批次连击在聚堆时逐件累计并保存快照，避免同时入队的多个批次错误共用最终连击值。
- 普通浏览器没有小红书 Storage，会显示不可持久保存提示。普通浏览器运行结果仅用于开发辅助，不是小工具功能、兼容性或交付验收。

## 验证边界

聚焦测试仅覆盖本轮自由聚堆、连续批次及受影响交互，不运行无关 Godot 全量测试。核心测试覆盖同款未集齐、连通分量、异款阻断/移开、旋转礼盒、确定 FIFO、零冷却、大 delta、第 2 关 18 件、吸附、盲袋、连击计价和换客价签。浏览器脚本使用真实鼠标，不直接调用业务结算函数。

最终仍必须上传同一 ZIP 到创服平台，依次完成：

1. 创服平台模拟器完整功能验证；
2. Android 真机扫码验证；
3. iOS 真机扫码验证。

以上三项均待用户验证，本地脚本与普通浏览器结果不能替代。
